Accessibility Statement

Effective Date: August 6, 2026

Greene Solutions LLC is committed to making Smyth accessible to all users, including those with disabilities. This Accessibility Statement describes our approach to accessibility and the features we have implemented.

1. Our Commitment

We strive to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA where applicable within the Smyth desktop application. While Smyth is a native desktop app rather than a web application, we apply these principles to ensure a usable experience for all.

2. Accessibility Features

Smyth includes the following accessibility features:

Keyboard navigation: All primary functions can be accessed via keyboard shortcuts.
Voice input: Users can interact with Smyth using voice-to-text input.
Dark mode: The interface defaults to a dark color scheme for reduced eye strain.
Resizable text: Text can be resized using standard macOS text scaling.
Screen reader compatibility: The app interface uses semantic markup compatible with VoiceOver.
High contrast: The interface uses sufficient color contrast ratios for readability.

3. macOS Accessibility Integration

Smyth integrates with the following macOS accessibility features:

VoiceOver for screen reading
Voice Control for hands-free operation
Switch Control for motor accessibility
Display accommodations for color blindness and sensitivity
Reduced motion and transparency options

4. Known Limitations

Some third-party content displayed within Smyth (such as web pages rendered by AI tools) may not fully conform to accessibility standards. We continue to work on improving accessibility in these areas.
