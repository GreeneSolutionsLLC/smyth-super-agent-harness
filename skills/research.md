# Research Skill

When the goal is to learn something, not do something.

## Process

1. **Define the question.** If the user gives a topic, restate it as 1–3
   specific questions.
2. **Search broadly first.** `web_search` for breadth, `deep_research` for
   depth on the most promising thread.
3. **Triangulate.** Three independent sources before a claim. Note conflicts.
4. **Cite everything.** Source URL + access date for every non-trivial fact.
5. **Synthesize last.** A research report without a "so what" is a list.

## Output shape

- TL;DR (3 bullets)
- Findings (with citations)
- Open questions / things to dig into next
- Sources

## When to use deep_research

- Open-ended ("what's the state of X in 2026")
- Comparison shopping ("best tools for Y")
- Anything where the answer will live longer than the conversation

## When to use web_search

- Quick fact lookups
- "Is X still true" verification
- Cheap breadth before committing to deep research
